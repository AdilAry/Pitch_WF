# Example: Broadband Gap Finder (dry run, 2026-11-02)

A finished project made with this template, as a reference. It was built in one day for a **mock** challenge, generated as a rehearsal for Since AI 2026. **It's not affiliated with or endorsed by DNA**, and the challenge, its mentor answers and its criteria are invented.

**What it is:** a Streamlit map of Varsinais-Suomi that ranks 1 km squares as fixed-wireless candidates, from Speedtest by Ookla open data (CC BY-NC-SA 4.0) and the Statistics Finland 1 km population grid (CC BY 4.0). Live app: https://broadband-gap-finder.streamlit.app/. The full project, with its code, is archived in `Documents\GitHub\Archive\2026-11_dryrun_broadband\`.

## Files

| File | What it shows |

| `video/` | The video repo's filled `CLAUDE.md`, its `PROGRESS.md`, the final `scenes.json` and `video.mp4` (104.7 s). |

## How to use it
- **For structure only.** Never copy its facts, numbers or thresholds into another project.
- **Known faults, kept as they were:** the judge's points are listed in `JUDGE_REVIEW.md`. They include the wrong tier order, cells too small for the data, and a weak headline. Read the review before treating any part as a model.
- **Template version:** it was built on the template before the dry-run fixes (production c3, videogen c2, before V1). Where its `CLAUDE.md` differs from the current `production/CLAUDE.md`, the current one wins.
- **Not copied into new projects:** the template's setup copies only `production/` and `videogen/`.
