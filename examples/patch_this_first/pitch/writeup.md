# Patch This First

**One line:** Paste your office's software list and get the three things to patch this week, each with a plain-language reason and a link to the fix, in Finnish or English.

## Description (~150 words)
For an invented 12-person office list, all three "fix this week" items are on CISA's catalog of flaws attackers already use, and each has a flaw used in ransomware: the FortiGate firewall first, then Windows 11 and Windows 10. Each card says what to do, why, and links to the vendor's fix. Two honest caveats: Windows 11 and 10 share the same 203 flaws, so that week is really two updates, and the tool doesn't check versions. 13 of the 16 programs matched; the other three are listed as "not matched", never called safe.

Patch This First is for the office manager or teacher who does the IT on the side. It matches the pasted list locally against the CISA Known Exploited Vulnerabilities catalog (1,766 entries) and ranks by one rule: ransomware first, then the EPSS attack forecast, then the newest addition. The list never leaves the laptop. The AI sees only four public facts per card.

## How I built it
- Built solo in a 2-hour template dry run on 2026-11-03, for a mock Traficom NCSC-FI challenge, in milestones: skeleton, data and rules, home screen, AI layer, polish, then a sceptical judge pass.
- Python 3.12 and Streamlit, run locally. Data: CISA KEV (one JSON file) and FIRST EPSS scores, both free and keyless, cached with their dates. If either download fails, the app uses the last saved copy and says so.
- Matching (`core/match.py`) normalises messy names ("ms" → Microsoft, "Fortinet VPN" → FortiOS) and splits comma-separated lines. A judge-pass probe of 54 messy names found 26 matches (one false). After two fixes, 37 match.
- Ranking (`core/rules.py`) is one sentence, shown in the app under "How the order is decided".
- Wording: template sentences in both languages by default. Google Gemini rewrites four public facts into two sentences, and a checker rejects any text that changes a number, says "vulnerable" or "risk", or adds a ransomware claim. 47 automated tests pass.
