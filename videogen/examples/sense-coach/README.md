# sense-coach: regression fixture and style version 0

A finished video from a real hackathon project, kept for two reasons only.

1. **Technical.** `npm run regress` renders this `scenes.json` with its `public/` media and compares the result
   with `out/video.mp4`. Change nothing here, or the test no longer means anything. It is also a working
   reference for the `scenes.json` format: visuals, cues, clips, captions.
2. **Version 0 of the style.** This is what the videos looked like before the style guide: screen recordings
   held for many seconds, captions carrying the meaning, no physical scene. Finding 6 of the Since AI 2026
   review says this style doesn't win. Keep it as the "before" to set the new style against.

**Don't copy its look.** For style, read the project repo's `docs/style/`, which `/entry` copies from the kit's
`style/` folder.
