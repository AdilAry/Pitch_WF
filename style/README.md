# My style (empty until v1)

Written from the practice remake of LoadLedger's first 20 seconds (`retrospective/TODO.md` item 4, finding 6).
Refined after each event; never rebuilt for a sponsor. `/entry` copies this folder into a project as
`docs/style/`, where only the accent colours change.

Planned contents of `STYLE.md` v1:
- **References:** the 4-12 images or stills it was drawn from, in `refs/`, one line each on what to keep.
- **Type and layout:** fonts, sizes, grid, how much text a frame may carry.
- **Palette:** base colours as hex, with two slots for the company's accent colours.
- **Motion rules:** no picture static for more than about 4 s; open on the physical problem; results by 20 s;
  key moments rebuilt as graphics; end on a number or a line. A music-only variant is allowed.
- **Opening and closing patterns.**
- **What it is not.**
- **Prompt preamble** for image tools, and the negative list.

Possible route for 3D shots (from the 20 Nov notes on the Blender post; not tried): a Blender Python script
that builds and renders the shots headless, with the clips used in videogen as `Clip` scenes.
